# Fuentes de información

Copia aquí los archivos `.pdf` o `.txt` que quieras usar como material de referencia. El chat los carga automáticamente y busca los fragmentos más relacionados con cada consulta.

- No es necesario editar código ni reiniciar el servidor al agregar archivos.
- Los PDF escaneados deben tener OCR para que el tutor pueda leer su texto.
- El contenido se usa como referencia, no como instrucciones para el tutor.
